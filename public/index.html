Stock-Comber is backed by a small JSON API — the same endpoints this dashboard uses. GET endpoints are public; writes are gated by STOCK_COMBER_API_KEY (pass ?key=… or an X-API-Key header). Base URL is this site.

API access log

WhenEndpointMethodStatusClientNote

Every API request is recorded here (when a database is configured), with the caller's method, the resulting status, and a non-secret client id (IP, or a key fingerprint). Requests over the configured rate limit are logged with status 429. Tune the limit under Settings → API.

GET
/api/screen?tickers=AAPL,MSFT&strategy=graham&custom=[…]
Run a live screen over the given tickers. strategy repeatable; custom is a JSON array of {metric,op,value} rules.
GET
/api/screen?funds=1 · /api/screen?fund=SPY&strategy=graham
Fund X-ray: funds=1 lists the bundled ETF/fund snapshots; fund=SYM (or fund_holdings=[{ticker,weight}]) deconstructs a fund and scores it fund-weighted against the strategies, reading only the stored universe (no upstream calls). Unscreened holdings return as pending.
GET
/api/analyze?ticker=AAPL
Full deep-dive for one ticker — all six lenses, composite scores, news & sentiment, and an illustrative value entry zone. Stores a run when a database is configured.
GET
/api/runs?limit=50 · /api/runs?results=all · /api/runs?audit=1
Run & search history; results=all returns every company across all runs, deduped to its latest result; audit=1 returns the API access log (optionally filter with &endpoint=screen).

📅 Scheduled report

When the hosted nightly “hidden gems” run fires. Each run draws a fresh seeded stratified-random set from the whole market — spread across sectors, market-cap sizes and volume sizes — so a different, well-balanced pool is screened every run. Sizes come from Polygon.io or Finnhub enrichment when a key is set (Settings → API keys).
Minutes past every Nth hour (the hour part is ignored in interval mode).
