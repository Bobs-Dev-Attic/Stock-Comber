Stock-Comber is backed by a small JSON API — the same endpoints this dashboard uses. GET endpoints are public; writes are gated by STOCK_COMBER_API_KEY (pass ?key=… or an X-API-Key header). Base URL is this site.
Read (public)
GET
/api/latest
The latest scheduled “hidden gems” report (JSON).
GET
/api/screen?tickers=AAPL,MSFT&strategy=graham&custom=[…]
Run a live screen over the given tickers. strategy repeatable; custom is a JSON array of {metric,op,value} rules.
GET
/api/analyze?ticker=AAPL
Full deep-dive for one ticker — all six lenses, composite scores, news & sentiment. Stores a run when a database is configured.
GET
/api/runs?limit=50 · /api/runs?results=all
Run & search history; results=all returns every company across all runs, deduped to its latest result.
GET
/api/universe?index=sp500&sector=Health%20Care&limit=10
Index templates (Dow / Nasdaq-100 / S&P 500) and universe slices.
GET
/api/tickers?q=app&limit=8
Ticker search / autocomplete.
GET
/api/queue?limit=50
The analysis queue (tickers awaiting a full analysis).
GET
/api/signals?runs=40
Plain BUY / WATCH / AVOID reads for recently analyzed tickers.
GET
/api/analytics
Aggregate analytics (runs over time, top tickers, sectors, sentiment, health bands).
GET
/api/settings
Effective configuration and key/DB status. Secrets are never returned.
GET
/api/thesis · /api/backtest?ticker=AAPL
Tracked investment theses; historical backtest for a ticker.
Write (needs STOCK_COMBER_API_KEY)
GET
/api/export?format=csv&run=51&key=…
Export a run's full per-company results as CSV or JSON.
POST
/api/settings?key=…
Save settings — thresholds, saved jobs, and the nightly schedule. Merges over stored settings.
POST
/api/queue?key=…
Enqueue tickers for a full analysis by the background worker.
POST DELETE
/api/thesis?key=…
Create or delete a tracked thesis.
